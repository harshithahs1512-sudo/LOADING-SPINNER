# Loading Spinner

## About the Project
This is a simple Loading Spinner project created using HTML and CSS. It displays a rotating animation to represent a loading process on a webpage.

## Technologies Used
- HTML
- CSS

## Features
- Smooth rotating animation
- Simple and clean design
- Continuous loading effect

## What I Learned
- CSS animations
- Keyframes
- Rotation using transform
- Animation timing and styling

## Conclusion
This project helped me understand how CSS animations work and how to create simple loading effects that make webpages more interactive and visually appealing.
